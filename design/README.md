# Figma wireframe starter

Create a Figma file named **SkillUp — Learning app**, then import the SVG screens in this folder (Figma supports SVG import) and arrange them as two presentation boards:

1. Auth and core app: Login, Registration, Home, Detail, Favorites/Profile.
2. Learning and preferences: API integration, Settings menu, Settings, Notifications.

Use the Figma desktop app to refine typography, spacing, and components. Capture both boards in Figma as `evidence/figma-evidence1.png` and `evidence/figma-evidence2.png`.
